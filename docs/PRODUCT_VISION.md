# Product Vision
Original open-world cultivation RPG for browsers: real-time combat, deep cultivation (realms, techniques, sects), living NPCs, alchemy, secret realms, bosses.
Benchmark: depth of Tale of Immortal (reference only; no shared IP/code/assets). Quality parity/superiority is a goal to be proven by benchmark + playtest, not asserted.
Pillars: (1) satisfying real-time combat feel, (2) meaningful cultivation progression, (3) world that reacts via NPC goals, (4) data-driven content scale.
Anti-goals: clones of protected IP, mockups claimed as features, unlicensed assets.
Commercial target: desktop browsers first.
